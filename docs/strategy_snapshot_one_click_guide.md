# 一键生成聚宽回测与严格导出脚本

双击桌面的“**一键生成聚宽策略快照**”，程序会读取服务器当前正在运行的策略版本和非敏感参数，生成并下载两份可以直接使用的聚宽脚本。它不会复制 SSH 私钥、Token、Webhook、账户或数据库。

## 生成步骤

1. 双击桌面图标“**一键生成聚宽策略快照**”。
2. 等待黑色窗口完成服务器版本检查、生成、下载、SHA-256 校验和本地发布。
3. 看到绿色的“**策略快照生成成功！**”才算完成。
4. 程序会自动打开 `output` 文件夹。

生成的主要文件：

| 文件 | 直接用在哪里 |
| --- | --- |
| `output/聚宽原生回测策略.py` | 聚宽“我的策略”中新建股票策略，选择分钟回测。 |
| `output/聚宽严格历史导出.py` | 聚宽“研究环境”中新建 Python 3 Notebook，整份粘贴到一个单元格。 |
| `output/聚宽策略快照.py` | 便携运行时和版本证据，日常不用单独操作。 |
| `output/strategy_snapshot_latest.zip` | 完整、去敏、带 manifest 的证据包。 |

## 两份脚本分别做什么

`聚宽原生回测策略.py` 让聚宽自己的撮合引擎展示收益、回撤、订单和日志。它在每个闭合的 5 分钟时点做决策，订单延迟到下一决策点镜像，并遵守实际持仓和 T+1 可卖数量。

`聚宽严格历史导出.py` 为服务器训练生成月度 strict ZIP：每个交易日 48 个五分钟决策点、约 30 个入选/拒绝候选、逐项 `available_at`、规则拒绝原因，以及候选的 D+10 价格路径。

两份文件由同一套时点策略内核生成，快照 ID、参数版本、特征版本和代码哈希一致。

## 不使用未来数据的规则

- 只使用决策时点及以前已经闭合的 5 分钟行情。
- MA5/10/20/30、ATR14、支撑和压力只使用决策日前的完整日线。
- 市值使用上一完整交易日估值；行业使用指定历史日期。
- 线上盘中观察池不展开个股新闻和龙虎榜，因此历史回放同样记 `news_score=0`，并明确保存 `intraday_watch_unexpanded`，不是拿当前新闻倒灌历史。
- 聚宽 CCTV 新闻没有可证明的盘中发布时间，同日市场新闻不进入当天盘中决策。
- 不足 30 根有效日线的股票不会伪造 MA30，会跳过并由后续候选补位。
- 任一特征的 `available_at > decision_at` 会立即失败。

## 什么时候重新生成

服务器策略代码或有效参数更新并受控重启后，再双击一次。策略没有变化时重复运行是幂等的，会得到同一快照；如果服务器文件比正在运行的服务更新，脚本会停止，防止导出未生效代码。

完整的日常操作见[严格历史数据三步说明](strict_history_three_step_guide.md)。

## 安全边界

- 不修改或重置 SSH 密钥、Token、Webhook、交易配置和数据库。
- 下载失败、哈希不符或敏感信息扫描失败时，不覆盖上一份有效文件。
- 快照只包含明确允许的参数、便携决策代码和版本证据。
- 原生回测是聚宽撮合验证；strict ZIP 是服务器训练依据。两者不能互相代替。
